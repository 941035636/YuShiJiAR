# 体验版锯齿反馈与修复

日期：2026-10-28。分支 codex/harmony-kivicube。新诊断版本：20261028-aa-1。

## 证据与原因

用户提供约 28.48 秒、592×1280 的体验版录屏 f046012ebb5a8e4828e770f3d7bdf15b.mp4。可见本尊主体、山、盾、法阵、全屏主界面；模型轮廓和细线显示粗糙。截图记录取帧 480×640、预览 17.7 帧/秒、定位 3.9 次/秒、绘制调用 2 ms。录屏编码 30fps 不是实际渲染帧率，调用耗时也不等于 GPU 完整耗时。

代码确认 preview.js 每帧把 canvas.width/height 设置成相机取帧尺寸：模型和相机都只绘制 480×640，再被 CSS 居中裁切并放大到手机屏幕。此前实现全屏时没有同时提高模型绘制像素，是本轮需要修正的主要问题。轮廓采样不足之外，模型贴图一直使用单层线性过滤，缩小时细节也可能闪烁。不能只凭录像确定手机系统抗锯齿是否生效，本轮新增实际状态记录。

## 修复

- 分离相机输入和 GPU 输出：识别、姿态估算、误差、原图四角仍使用取帧坐标；相机纹理仍上传原 480×640，不增加识别计算量。背景与模型共用原比例、投影和裁切，提高输出像素不会改变模型位置。
- 「清晰」默认按显示画布宽度与设备像素密度计算目标，上限密度 2、最长边 1600、约 160 万像素；「高清」上限密度 2.5、最长边 2048、约 240 万像素。另受 GPU 纹理和深度缓冲尺寸约束。上限防止盲目按高 DPR 扩大显存和绘制量。
- 「流畅」恢复取帧尺寸绘制，便于与此前版本对比。三个档位可即时切换并存入已有本机校准，不下载或重载模型，不重启追踪/音频。
- 显式请求系统抗锯齿，读取 getContextAttributes 的实际结果。清晰/高清在系统未提供抗锯齿时使用 FXAA 后处理：场景先画入颜色/深度缓冲，再沿亮度边缘平滑呈现。保持 FBO 纹理上下方向一致，不反馈采样正在绘制的附件。
- 后处理程序或缓冲创建失败时释放资源，回到直接绘制，诊断记录原因；不让此错误阻断相机与已有模型。分辨率不变时复用附件，换档/尺寸变化时重建，退出全部释放。
- 对二次幂模型贴图生成 mipmap 并用三线性缩小过滤，减少细节闪烁。WebGL 1 非二次幂贴图继续保留线性过滤和着色器 REPEAT，避免使山等现有特效纹理失效。mipmap 会增加相应贴图的显存。
- 调试面板及复制诊断新增「3D 绘制尺寸」「抗锯齿状态」「回退原因」，不再把相机取帧大小误当作模型输出大小。

提高的是 3D 采样和边缘处理，不会凭空增加 480×640 相机背景的细节。GPU 绘制量会上升，实际提升和帧率需要鸿蒙手机复测；没有承诺维持原帧率或完全消除全部材质闪烁。

## 验证

- 新增 test-native-antialias.cjs：输出像素/尺寸上限、宽高比、源坐标姿态与相机上传、系统抗锯齿/FXAA/分配失败三条路径、附件复用、换档重建和完整资源释放通过。
- 页面测试覆盖画质切换不重载；模型渲染测试增加 POT 生成 mipmap、NPOT 禁用 mipmap，既有动画/透明/取消回调/资源释放回归通过。
- 模型/姿态、特效、音频、稳定器、平台路由检查通过；本页 WXML/WXSS 用微信工具自带编译器检查通过，项目静态检查零错误。
- 桌面隐藏 WGL 实际编译并渲染运行时 FXAA 着色器，用同一 592×800 投影绘制至 1184×1600，并检查纹理方向和完整模型/特效，无 OpenGL 错误：[桌面参考输出](../recovery-reports/native-antialias-2026-10-28/reference-pbr-fxaa.png)。参考脚本用桌面帧缓冲拷贝验证后处理，手机 FBO 生命周期另有模拟回归，均不能代替鸿蒙验证。
- GPU 参考工具第三个参数现在支持 1～2 倍输出。例如 node recovery-tools/export-native-visual-reference.cjs 输出目录 2，然后运行 render-native-visual-reference.py 输出目录/reference-pbr.json。

## 真机复测

重新编译并生成体验版，在调试页确认诊断版本 20261028-aa-1。

1. 保持同一识别图占比与视角，先使用默认「清晰」。截图记录相机取帧尺寸、3D 绘制尺寸、抗锯齿状态、实际预览帧率与定位频率。
2. 同一场景依次切「流畅」「清晰」「高清」，各录至少 15 秒；检查耳尖、头发、身体轮廓、牌子文字、盾和法阵细线的台阶/闪烁，比较帧率与发热。
3. 移动/倾斜/移开再识别，确认模型和绿框仍贴合。换全屏/调试、前后台、暂停/重新开始，观察声音和特效是否正常。
4. 若高清明显掉帧，先用清晰；清晰仍慢则退回流畅并复制诊断。FXAA 不可用时应有原因提示，模型仍可显示。
