# 鸿蒙原生 AR 画面优化与交接

日期：2026-10-28。分支：codex/harmony-kivicube。诊断版本：20261028-visual-1。

## 本轮结果

完成上一轮计划中的素材对照、增强材质、特效色彩和正式主视图改造。离线回归、桌面 GPU 着色器编译及参考渲染通过。本轮增强材质和新主视图尚未在鸿蒙手机复测，不能沿用上一版录屏作为新代码的验收结论，也不能按 XR-Frame 原版品质验收。

此前用户的纯血鸿蒙 7.0 体验版录屏已证明旧版原生路线能显示完整模型/特效并随识别图变化，抽样预览约 18～23 帧/秒。本轮继续使用该原生路线，无需新增服务器、付费 AR SDK 或 web-view 方案。

## 素材与材质

- 默认「原版对照素材」：AR-YSJ/Model/GoldModel/taishanshigandang.glb，8,483,976 字节，4 网格/12 贴图。原 XR-Frame 识别回调会启用此分支，亮牌子也更接近参考视频。但源码不能单独证明录屏当时只绘制这个分支；此名称只表示对照素材，最终业务版本映射仍待确认。
- 保留「墨玉素材」：AR-YSJ/Model/taishanshigandang_yu.glb，8,688,904 字节，5 网格/15 贴图。多出的正面牌子网格使用偏暗基础色；增强光照不会自动把它变成另一份牌子。两份 URL 本轮 HEAD 均 HTTP 200，合法域名沿用已成功加载的版本。
- GLB 读取补齐切线、法线、金属度/粗糙度和遮蔽。ORM 图片的字节及 GPU 纹理复用，避免重复上传。对实际素材中不正交的切线正交化，保留手性。
- 基础色按 sRGB 解码，法线/ORM 按线性数据读取。增强着色器加入 GGX/Smith/Schlick 高光、两侧灯光、半球环境项与解析式棚灯反射，再进行曝光、亮部压缩和 sRGB 输出。环境强度 2、主光 3，但渲染器不同，不能视为与原版效果完全一致。
- 环境反射仍为解析近似，没有新增 HDR 环境贴图或屏幕泛光；当前仍是针对现有素材的有限渲染器。
- 同一模型、姿态和时间线上可切换增强/简化材质，无需重新下载。增强着色器编译/链接失败或纹理单元不足时自动编译简化版本，只上传基础色贴图；复制诊断包含回退原因。此处理不代表所有 GPU 故障均可恢复。

## 特效与主界面

- 盾、山、法阵、文字保留原动画关键帧、时长、相对布局、透明排序与混合。增强模式给特效单独增加曝光与亮部压缩，默认亮度 180%，使橙色亮部向亮黄过渡；可在调试面板调整。
- 默认使用占满可用视窗的 AR 主视图，复用原蜂窝边框，提供开始/暂停、声音和调试设置；隐藏绿框。
- 相机帧与模型继续合成到同一张 WebGL canvas，再整体居中等比裁切，避免分别缩放错位。调试模式显示完整取帧画面、绿框和原生相机小窗，保留原 canvas。
- 调试面板保留素材/材质切换、模型/特效重试、仅绿框、特效开关、讲解重播、帧率、定位耗时和姿态误差。可调大小、上下位置、视角、主体曝光和特效亮度。
- 参数经范围限制后存入本机 ysj-native-visual-v1。切换素材/恢复默认会停止追踪、重置动画与音频并重载；材质/曝光调整保留追踪。复制诊断包含参数、运行 AppID、素材 URL、加载阶段及性能记录。
- 仍由用户点击「开始体验」启动相机。后台、停止、退出继续释放监听并停止声音。Android/iOS 原 XR-Frame 入口未修改，其余五套鸿蒙场景待迁移。

## 下次真机操作

1. 公司电脑拉取此分支并同步 LFS，用当前 AppID 重新编译、生成新体验版。「调试设置」内版本应为 20261028-visual-1，不能复用旧二维码判断本轮效果。
2. 进入本尊原生入口，等待模型/特效就绪，点击「开始体验」，扫描完整 recovery-assets/cards/tssgd.jpg。检查全屏相机、模型、蜂窝边框和底部按钮是否正常覆盖，允许相机后是否连续取帧。
3. 默认对照素材检查身体高光、金色装饰及亮牌子；调试中原地切换简化/增强，各录约 15 秒，记录实际预览帧率、绘制调用耗时和发热。若增强明显变慢，先保留简化模式并复制诊断，再按机型调节质量。
4. 切换墨玉，确认暗牌子区别并确定最终业务素材。不要用全局曝光抹平素材差异。
5. 同一卡片占比与相近视角下比较原版，校准大小/位置/视角，观察山/法阵层次与透明交叉。全屏可能裁掉边框，调试可看完整边框，不应误判为定位错误。
6. 至少运行两个完整 37.5 秒循环，验证遮挡/移开/重新扫描、快速倾斜、声音/重播、前后台和连续 3 分钟，检查音画暂停/恢复及贴合。

下一轮优先依据真机修正曝光、高光、裁切和 GPU 成本，再决定真实环境贴图、内参标定或其他场景迁移。继续原生路线。
