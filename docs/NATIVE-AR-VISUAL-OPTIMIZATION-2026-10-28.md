# 鸿蒙原生 AR 画面优化与交接

日期：2026-10-28，2026-10-29 合并正式入口与分组特效参数。分支：codex/harmony-kivicube。当前内部版本：20261029-experience-2。

> 后续体验版锯齿反馈已处理，见 [锯齿修复记录](NATIVE-AR-ANTIALIAS-2026-10-28.md)；正式入口已移除面向用户的调试面板，见 [正式入口与开发基线](NATIVE-AR-BASELINE-2026-10-28.md)。当前工作树在两者基础上合并分组特效参数。

## 本轮结果

完成素材对照、增强材质、正式主视图和第二轮特效对比度改造。用户提供的 12.78 秒真机录屏已实际证明 `visual-1` 能持续显示全屏相机、主模型和动画特效，目标移动时未观察到明显的大幅跳变，录屏也包含有效音轨。录屏没有显示调试面板，视频文件的 30 帧/秒只是编码帧率，不能当作小程序实际预览帧率；录像也没有覆盖目标丢失/重捕获和完整 37.5 秒动画周期。

录屏暴露出统一 180% 特效曝光使黄色文字和部分金色区域过曝。`visual-2` 已将亮度拆到各特效组，并为文字增加深金对比色；离线回归、增强/兼容两套桌面 GPU 着色器编译及参考渲染通过。该第二轮参数仍需生成新体验版真机复测，不能把 `visual-1` 录屏当作 `visual-2` 的验收结论。

此前用户的纯血鸿蒙 7.0 体验版录屏已证明旧版原生路线能显示完整模型/特效并随识别图变化，抽样预览约 18～23 帧/秒。本轮继续使用该原生路线，无需新增服务器、付费 AR SDK 或 web-view 方案。

## 素材与材质

- 默认「原版对照素材」：AR-YSJ/Model/GoldModel/taishanshigandang.glb，8,483,976 字节，4 网格/12 贴图。原 XR-Frame 识别回调会启用此分支，亮牌子也更接近参考视频。但源码不能单独证明录屏当时只绘制这个分支；此名称只表示对照素材，最终业务版本映射仍待确认。
- 保留「墨玉素材」：AR-YSJ/Model/taishanshigandang_yu.glb，8,688,904 字节，5 网格/15 贴图。多出的正面牌子网格使用偏暗基础色；增强光照不会自动把它变成另一份牌子。两份 URL 本轮 HEAD 均 HTTP 200，合法域名沿用已成功加载的版本。
- GLB 读取补齐切线、法线、金属度/粗糙度和遮蔽。ORM 图片的字节及 GPU 纹理复用，避免重复上传。对实际素材中不正交的切线正交化，保留手性。
- 基础色按 sRGB 解码，法线/ORM 按线性数据读取。增强着色器加入 GGX/Smith/Schlick 高光、两侧灯光、半球环境项与解析式棚灯反射，再进行曝光、亮部压缩和 sRGB 输出。环境强度 2、主光 3，但渲染器不同，不能视为与原版效果完全一致。
- 环境反射仍为解析近似，没有新增 HDR 环境贴图或屏幕泛光；当前仍是针对现有素材的有限渲染器。
- 同一模型、姿态和时间线上可切换增强/简化材质，无需重新下载。增强着色器编译/链接失败或纹理单元不足时自动编译简化版本，只上传基础色贴图；复制诊断包含回退原因。此处理不代表所有 GPU 故障均可恢复。

## 特效与主界面

- 盾、山、法阵、文字保留原动画关键帧、时长、相对布局、透明排序与混合。渲染器不再共用单一曝光，分组基准为盾 135%、山 110%、法阵 130%、文字 55%；文字基于原材质增加深金对比色，降低其与亮山背景混色。正式入口把整体倍率固定为 100%。
- 分组曝光同时接入增强与兼容简化着色器；即使设备因着色器能力回退，亮度校准也不会失效。主体曝光仍为 100%，没有用全局变暗掩盖特效问题。
- 默认使用占满可用视窗的 AR 主视图，复用原蜂窝边框，底部只提供开始/暂停、声音和重播讲解；隐藏绿框和开发信息。
- 相机帧与模型继续合成到同一张 WebGL canvas，再整体居中等比裁切，避免分别缩放错位。远端新增的独立高分辨率输出、系统抗锯齿与 FXAA 回退保持生效。
- 正式入口固定使用对照素材、增强材质、清晰画质、模型大小 100%、上下位置 0、视角 50°、主体曝光 100%和特效整体倍率 100%；不读取旧调试缓存，避免不同手机历史配置改变正式效果。
- 仍由用户点击「开始体验」启动相机。后台、停止、退出继续释放监听并停止声音。Android/iOS 原 XR-Frame 入口未修改，其余五套鸿蒙场景待迁移。
