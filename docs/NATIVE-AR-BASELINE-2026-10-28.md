# 本尊 AR 正式入口与开发基线

日期：2026-10-28；分支：codex/harmony-kivicube。

## 基线

用户已反馈抗锯齿版本“效果非常好”，因此将 98fca5f 标记为 baseline/native-ar-20261028。该标记固定用户认可的渲染代码，后续开发可回到此提交对照。反馈证明用户认可当前视觉效果，不代表其他五个场景、持续运行或平台审核均已完成验收。

本轮在该渲染基线上整理正式体验入口，未调整识别算法、模型几何、光照公式、抗锯齿实现、动画时间或音频门控。2026-10-29 合并分组特效曝光与文字对比色后，页面内部版本为 20261029-experience-2，不展示给普通用户；这组新参数仍待真机复测。

## 用户入口

场景选择页新增常驻「本尊 AR 体验」卡片，点击进入 pages/ar-native-track/index。开发版、体验版和正式版均可显示，Android/iOS/鸿蒙均有此独立入口。

原有「本尊」图片卡片继续按平台分流：鸿蒙进入原生体验，Android/iOS 保持原 XR-Frame。其他五套场景的路由与迁移状态不变。

删除选择页中的能力验证、相机检测及原生追踪测试入口，并从 app.json 取消注册 ar-native-probe / ar-self-hosted 测试分包。历史源码保留在仓库中供维护，不再作为正式应用页面开放。

## 正式体验页

- 保留全屏相机、蜂窝边框、模型与四组特效。
- 底部只有「开始/暂停体验」「开启/关闭声音」「重播讲解」。
- 移除调试设置按钮、参数面板、素材/材质/画质切换、仅绿框、AppID 和帧率/匹配数等开发数据显示。无隐藏点击或 URL 参数开启调试界面的路径。
- 普通用户只看到准备、识别、相机权限/中断、加载失败等简明提示，不直接展示文件 URL、素材版本或原始下载错误。
- 模型失败可以重新加载；部分特效失败仍可重试，不因移除调试面板而丢失恢复能力。声音失败提示可关闭后重开。
- 相机继续由点击开始触发，暂停/离开/后台停止取帧与声音，返回后可重新开始。
- 画质固定清晰（balanced），增强材质，使用当前代码默认对照素材，模型大小 100%、上下位置 0、视角 50°、主体曝光 100%。特效整体倍率固定为 100%，各组基准为盾 135%、山 110%、法阵 130%、文字 55%并使用深金对比色；声音与四组特效默认开启。
- 不读取旧 ysj-native-visual-v1 调试缓存，避免此前本机调试值影响正式用户表现；也不删除缓存，以便维护版本需要时对照。数值是已提交代码默认值，并非从用户手机读取的私有调试参数。
- 内部加载诊断、离线工具和测试保留供维护，普通用户无法从页面打开。

## 验证与后续

入口测试覆盖三类平台的正式卡片导航、原有平台分流、无测试页注册、开发控件不出现在正式模板、失败重试按钮保留。页面测试验证旧缓存不能改变固定基线，原有取帧、音频可见性和会话释放回归通过。抗锯齿及音频专项回归通过。

两个修改页面均使用微信工具自带 WXML/WXSS 编译器检查，项目静态验证零错误。新入口和 UI 尚需重新生成体验版，在真机点击完整走一遍；本轮未上传/审核/发布微信正式版本。

检查路径：场景选择 → 本尊 AR 体验 → 开始体验 → 对准完整 tssgd.jpg。检查首次授权、加载失败重试、特效、静音/重播、暂停恢复、前后台；确认看不到调试面板。与基线比较视觉效果，并连续运行 3～5 分钟观察帧率与发热。

本地 project.config.json 中用户更改的 AppID 保持原状，不纳入此次源码提交。旧锯齿修复细节见 [抗锯齿记录](NATIVE-AR-ANTIALIAS-2026-10-28.md)。
